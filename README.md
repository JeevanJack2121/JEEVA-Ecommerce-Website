# JEEVA – Full-Stack E-Commerce Web Application

## About the Project
JEEVA is a responsive e-commerce web application developed as part of my MCA final-year academic project. It provides a user-friendly online shopping experience with essential shopping features.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- MongoDB
- REST API

## Key Features
- User Registration and Login
- Product Browsing
- Product Search
- Shopping Cart Management
- Order Management
- Responsive User Interface

## Developed As
MCA Final-Year Project – Artificial Intelligence & Machine Learning
